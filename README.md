# 体外循環技術認定士 500問 学習アプリ

体外循環技術認定士の対策問題集（全500問・10分野）をブラウザで解くための、
依存ライブラリなしの静的Webアプリです。オフライン（PWA）でも動作します。

## 機能

- **分野別練習** — 10分野×50問を順番に。1問ごとに正誤と解説を即時表示
- **ランダム / 模擬試験** — 20 / 50 / 100 / 500問をランダム出題。終了後にまとめて採点・解説
- **その回ごとの採点** — 終了時に正答率・分野別の内訳・誤答の解説一覧を表示
- スマートフォン表示に最適化
- **オフライン動作** — Service Worker によりキャッシュ後はネット接続不要

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（UI・ロジック・スタイル） |
| `questions.js` | 問題データ（`window.QUIZ_DATA`） |
| `questions.json` | 同じ問題データのJSON版（他用途向け） |
| `sw.js` | Service Worker（オフラインキャッシュ） |
| `manifest.webmanifest`, `icon.svg` | ホーム画面へのインストール用 |
| `.nojekyll` | GitHub Pages で Jekyll 処理を無効化 |

## GitHub Pages での公開手順

```bash
# 1. このフォルダでリポジトリを作成
git init
git add .
git commit -m "体外循環技術認定士 500問 学習アプリ"

# 2. GitHub にリポジトリを作成して push（例）
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git branch -M main
git push -u origin main
```

3. GitHub のリポジトリ画面で **Settings → Pages** を開く
4. *Source* を **Deploy from a branch**、Branch を **main / (root)** にして保存
5. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

### スマートフォンにインストール（オフライン利用）

公開URLをスマートフォンのブラウザで開き、

- iOS(Safari)：共有ボタン →「ホーム画面に追加」
- Android(Chrome)：メニュー →「アプリをインストール」

一度読み込めば、以降は機内モードでも起動できます。

## ローカルで試す

`index.html` をブラウザで直接開くだけで動作します（Service Worker は
`http(s)` 配信時のみ有効になりますが、アプリ自体は `file://` でも動きます）。

## データについて

成績は1回の出題セッション内でのみ集計します。**保存・蓄積は一切行いません**
（画面を閉じたりホームへ戻ると消えます）。サーバ・データベース・外部通信は使用しないため、
リンクを共有された相手も、登録なしでそのまま利用できます。

## 注意

本アプリは学習を目的とした**非公式**の予想問題集です。本試験は五肢択一ですが、
学習効率を考慮し四肢択一で構成しています。数値・設定値は一般的な教科書的知識に
基づくもので、実際の臨床は各施設のプロトコル・最新ガイドラインに従ってください。
